# Security policy

This repository is a public source snapshot of Corion. It must not contain:

- API keys, passwords, tokens or OAuth credentials
- database URLs or production environment files
- customer documents, uploads, screenshots or personal data
- local agent state, task queues, chat/session exports or internal notes

If you discover a credential or personal data in this repository, do not open an issue containing the value. Contact the repository owner privately and revoke/rotate any exposed credential immediately.

Production configuration, customer data and operational runtime state are maintained outside this public repository.
