### ✨ 2️⃣ **Design și stiluri pentru pagina Impressum**

În `tailwind.config.ts`, asigură-te că ai activat **dark mode** și culorile de brand:
```js
module.exports = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: '#C00020', // roșu pentru linkuri
        darkBackground: '#121212', // fundal negru
        lightText: '#FFFFFF', // text alb
      },
    },
  },
};
```

În `styles/global.css`, asigură-te că există stiluri pentru text și fundal:
```css
body {
  background-color: #121212;
  color: #FFFFFF;
}

h1, h2, h3 {
  color: #FFFFFF;
}
```
