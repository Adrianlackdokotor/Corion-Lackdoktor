### 🌑 2️⃣ **Activarea Dark Mode**

1. În `tailwind.config.ts`, activează dark mode global:
   ```js
   module.exports = {
     darkMode: 'class', // activăm dark mode pe întreaga pagină
     theme: {
       extend: {
         colors: {
           primary: '#C00020', // culoare roșie pentru contrast
           darkBackground: '#121212', // fundal negru
           lightText: '#FFFFFF', // text alb
         },
       },
     },
   };
   ```

2. În componenta principală a paginii (`App.tsx` sau `index.tsx`), setează un `className` pe tag-ul `<html>` pentru dark mode:
   ```tsx
   <html className="dark">
     <body className="bg-darkBackground text-lightText">
       ...
     </body>
   </html>
   ```

3. În `index.tsx`, adaugă un buton de schimbare între modurile **light** și **dark**:
   ```tsx
   const toggleDarkMode = () => {
     const currentClass = document.documentElement.classList.contains("dark");
     document.documentElement.classList.toggle("dark", !currentClass);
   };

   return (
     <button onClick={toggleDarkMode} className="absolute top-5 right-5 p-3 bg-primary text-white rounded-full">
       🌙/🌞
     </button>
   );
   ```
