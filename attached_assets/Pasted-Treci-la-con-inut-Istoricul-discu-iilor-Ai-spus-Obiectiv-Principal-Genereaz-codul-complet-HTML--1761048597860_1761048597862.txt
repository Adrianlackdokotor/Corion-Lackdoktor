FAQ – Häufig gestellte Fragen
1. Wie lange dauert eine Reparatur?
Das hängt von der Art des Schadens ab.

Kleine Smart-Repair-Arbeiten: in der Regel innerhalb eines Tages erledigt.

Unfallschäden: meist 3–5 Werktage, abhängig vom Ersatzteilbedarf.

Wir informieren Sie immer transparent über den Zeitplan und halten Sie auf dem Laufenden.

2. Kann ich während der Reparatur ein Ersatzfahrzeug bekommen?
Ja! Wir bieten unseren Kunden Leihwagen oder einen Hol- & Bringservice im Umkreis von 20 km an – damit Sie mobil bleiben, während wir Ihr Auto instand setzen.

3. Muss ich den Schaden selbst bei der Versicherung melden?
Nein, das übernehmen wir gerne für Sie.
Als zertifizierter Gutachterbetrieb kümmern wir uns um die komplette Schadensabwicklung – inklusive Kommunikation mit Ihrer Versicherung.

4. Was kostet ein Smart Repair?
Das hängt von der Größe und Art des Schadens ab. Typische Preisbeispiele:

Kratzer an Stoßstange: ab 120 €

Kleine Delle: ab 90 €

Felgenreparatur: ab 80 €

Wir erstellen Ihnen auf Wunsch kostenlos einen individuellen Kostenvoranschlag.

5. Ist Smart Repair so haltbar wie eine normale Lackierung?
Ja – bei fachgerechter Ausführung ist der Unterschied kaum sichtbar und die Reparatur genauso langlebig wie eine Voll-Lackierung.
Wir verwenden nur Materialien in Erstausrüsterqualität (OEM).

6. Was passiert, wenn ich nicht zufrieden bin?
Ihre Zufriedenheit steht für uns an erster Stelle. Sollte einmal etwas nicht Ihren Erwartungen entsprechen, beheben wir es umgehend – ohne zusätzliche Kosten.

🧩 src/components/PageLayout.jsx
import React from "react";
import Head from "next/head";
import Hero from "./Hero";
import Section from "./Section";
import Gallery from "./Gallery";
import TestimonialSlider from "./TestimonialSlider";
import ContactForm from "./ContactForm";
import AiZone from "./AiZone";

/**
 * PageLayout.jsx
 * 
 * Componentea universală pentru toate paginile site-ului.
 * Preia conținutul dintr-un fișier JSON (de ex. /data/pages/home.json)
 * și îl redă în secțiuni dinamice, cu SEO și LLM-ready markup.
 */

export default function PageLayout({ data }) {
  const {
    title,
    subtitle,
    hero,
    sections,
    form,
    testimonials,
    locations,
    seo,
    cta,
  } = data;

  return (
    <>
      {/* SEO + META TAGS */}
      <Head>
        <title>{seo?.metaTitle || title}</title>
        <meta
          name="description"
          content={seo?.metaDescription || subtitle || ""}
        />
        <meta name="robots" content="index, follow" />
        <meta property="og:title" content={seo?.metaTitle || title} />
        <meta
          property="og:description"
          content={seo?.metaDescription || subtitle}
        />
        <meta property="og:image" content={hero?.image || "/images/logo.svg"} />
        <meta property="og:type" content="website" />
      </Head>

      {/* HERO SECTION */}
      {hero && (
        <Hero
          title={title}
          subtitle={subtitle}
          image={hero.image}
          cta={hero.cta}
          ctaLink={hero.ctaLink}
        />
      )}

      {/* MAIN SECTIONS */}
      <main>
        {sections &&
          sections.map((section, index) => (
            <Section
              key={index}
              title={section.title}
              content={section.content}
              items={section.items}
              cta={section.cta}
              link={section.link}
            />
          ))}

        {/* TESTIMONIALS */}
        {data.testimonials && <TestimonialSlider testimonials={data.testimonials} />}

        {/* FORMULAR DE CONTACT */}
        {form && <ContactForm formData={form} />}

        {/* GALERIE */}
        {data.gallery && <Gallery images={data.gallery} />}

        {/* LOCAȚII */}
        {locations && (
          <section className="locations">
            <h2>Unsere Standorte</h2>
            <div className="location-list">
              {locations.map((loc, i) => (
                <div key={i} className="location-item">
                  <h3>{loc.city}</h3>
                  <p>{loc.address}</p>
                  <p>📞 {loc.phone}</p>
                </div>
              ))}
            </div>
          </section>
        )}

        {/* CALL TO ACTION */}
        {cta && (
          <section className="cta-block">
            <h3>{cta.text}</h3>
            <a href={cta.link} className="btn-primary">
              {cta.textBtn || "Jetzt informieren"}
            </a>
          </section>
        )}
      </main>

      {/* AI SEO ZONE */}
      <AiZone data={data} />
    </>
  );
}

🧩 AiZone.jsx (componentă simplă pentru AI SEO)
import React from "react";

/**
 * Componentă ascunsă pentru AI SEO (ChatGPT, Gemini, Perplexity)
 * Include text structurat și Q&A sintetizate pentru crawling.
 */

export default function AiZone({ data }) {
  if (!data || !data.title) return null;

  return (
    <div style={{ display: "none" }}>
      <h1>{data.title}</h1>
      <p>{data.subtitle}</p>

      {data.sections &&
        data.sections.map((s, i) => (
          <div key={i}>
            <h2>{s.title}</h2>
            <p>{s.content}</p>
          </div>
        ))}

      {data.faq &&
        data.faq.map((f, i) => (
          <div key={i}>
            <strong>{f.question}</strong>
            <p>{f.answer}</p>
          </div>
        ))}

      <p>Kontaktiere Corion Lackdoktor für Smart Repair, Gutachten und Fahrzeugpflege in Hofheim, Wiesbaden und Mainz-Kastel.</p>
    </div>
  );
}
