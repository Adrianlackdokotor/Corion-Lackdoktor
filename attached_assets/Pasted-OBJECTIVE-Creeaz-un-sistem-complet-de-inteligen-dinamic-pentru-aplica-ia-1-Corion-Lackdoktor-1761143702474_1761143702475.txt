### 🧩 2️⃣ `appStorage.ts` – Stocare persistentă (user sessions)

Implementare simplă cu fallback local (`localStorage` → `Supabase` dacă există).
```ts
export const appStorage = {
  async saveSession(sessionId: string, data: any) {
    localStorage.setItem(sessionId, JSON.stringify(data));
  },
  async getSession(sessionId: string) {
    const item = localStorage.getItem(sessionId);
    return item ? JSON.parse(item) : null;
  },
  async deleteSession(sessionId: string) {
    localStorage.removeItem(sessionId);
  },
};
```
Structură stocare:
```json
{
  "userId": "uuid",
  "timestamp": "2025-10-22T13:00:00Z",
  "actions": ["visited_home", "clicked_offer", "opened_chat"],
  "preferences": {
    "language": "de",
    "interest": "smart-repair"
  }
}
```
