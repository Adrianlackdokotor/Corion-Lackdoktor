### 🧱 1️⃣ Setup & Environment Security
1. Creează fișierul `.env` în rădăcina proiectului (dacă nu există).
2. Adaugă:
   ```
   OPENAI_API_KEY=${process.env.OPENAI_API_KEY_CORIONLACKDOKTOR}
   ```
   sau, dacă rulează pe Replit:
   - Mergi la **Tools → Secrets** și definește:
     ```
     OPENAI_API_KEY_CORIONLACKDOKTOR=***************
     ```
   (cheia completă din sistemul Corion, fără ghilimele)

3. Asigură-te că fișierul `.env` este adăugat în `.gitignore`:
   ```
   .env
   ```

---

### ⚙️ 2️⃣ Backend API Connection
Editează fișierul `server/routes/ai.ts` (sau endpointul echivalent) pentru a folosi cheia din environment:

```ts
import dotenv from "dotenv";
dotenv.config();

const OPENAI_API_KEY = process.env.OPENAI_API_KEY_CORIONLACKDOKTOR;

if (!OPENAI_API_KEY) {
  console.error("❌ Lipsă cheie OpenAI API! Verifică .env sau Secrets Replit.");
}

router.post("/", async (req, res) => {
  const { prompt } = req.body;

  const response = await fetch("https://api.openai.com/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${OPENAI_API_KEY}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "gpt-4o-mini",
      messages: [
        { role: "system", content: "You are Corion AI assistant for the auto repair website." },
        { role: "user", content: prompt }
      ],
    }),
  });

  const data = await response.json();
  res.json({ reply: data.choices?.[0]?.message?.content });
});
```

✅ Toate cererile GPT trec prin server, nu din frontend → cheia rămâne protejată.

### 🤖 3️⃣ GPT Agent Integration
Actualizează fișierul `client/src/agents/CorionAgent.ts` pentru a trimite prompturile către backend:

```ts
export async function askCorionAgent(prompt: string) {
  const res = await fetch("/api/ai", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ prompt }),
  });
  const data = await res.json();
  return data.reply;
}
```
